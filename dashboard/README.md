# Helping Hand - Admin Dashboard

A modern, enterprise-level admin dashboard built with Next.js, TypeScript, and Tailwind CSS.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) with your browser.

### Build

```bash
npm run build
npm start
```

## Features

- User Management (Approve/Reject/Suspend users)
- Blood Donation Requests Management
- Education Support Requests Management
- Martyrs' Family Support Requests Management
- Real-time Dashboard Analytics
- Responsive Design
- Enterprise-level UI/UX

## Tech Stack

- **Framework:** Next.js 14
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React
- **API Client:** Axios
